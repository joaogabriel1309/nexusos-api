# Preferência de tema

- A interface oferece os temas claro, escuro e sistema a todo usuário autenticado.
- A preferência é local ao navegador e deve persistir entre sessões sem alterar contratos do backend.
- No modo sistema, mudanças na preferência de cores do dispositivo são aplicadas automaticamente.
- Estados de negócio mantêm significado por texto e contraste; a cor é apenas um reforço visual.
- Formulários, cards, tabelas, badges, menus e mensagens devem usar tokens semânticos e permanecer legíveis nos dois temas.
