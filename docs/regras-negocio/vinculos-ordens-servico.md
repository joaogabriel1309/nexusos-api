# Vinculos entre ordens de servico

- O vinculo entre duas OS e bidirecional: ao relacionar A com B, ambas passam a apresentar a outra como vinculada.
- Uma OS nao pode ser vinculada a si mesma e vinculos duplicados sao ignorados.
- Apenas administradores podem alterar vinculos. A consulta segue a visibilidade normal da OS; desenvolvedores nao ganham acesso a uma OS apenas por ela estar vinculada a outra.
- Ao substituir os vinculos de uma OS, os relacionamentos removidos deixam de aparecer nos dois lados.
- Na listagem de OS finalizadas, cada OS finalizada continua sendo a linha principal e suas OS vinculadas sao apresentadas junto dela, independentemente do status das vinculadas.
