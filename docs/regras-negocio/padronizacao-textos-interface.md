# Padronização dos textos da interface

- Todo texto exibido ao usuário deve ser escrito em português brasileiro, com acentuação e ortografia corretas.
- Rótulos, títulos, botões, mensagens, descrições, estados vazios, textos de ajuda e metadados visíveis seguem a mesma regra.
- Identificadores técnicos, nomes de variáveis, rotas, valores de enumeração e contratos de API não são alterados por essa padronização.
- Conteúdo dinâmico recebido do backend é preservado; a regra se aplica aos textos estáticos mantidos pelo frontend.
